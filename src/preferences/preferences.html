Preferences

Adjust application settings. These are placeholders for styling review.

General

General application settings and basic behavior toggles.

Application Appearance Determines whether application light mode or dark mode is enabled.
Primary Application Color Sets the primary accent color used for all headers, titles, and subheaders.


Default Map View Type Sets the default map view type used in the geofence editor.

Live Interface

Application preferences for the GCS launch control interface.

Live Data

Application preferences for the live data interface.

Geofence Editor

Application preferences for the geofence editor interface.

Default Region Restriction Set whether newly created regions are restricted or unrestricted by default.
Default Region Visibility Set whether newly created regions are visible or hidden by default.
Default Region Fill Color Set the default color all regions have when first created.
Default Region Border Color Set the default border color all regions have when first created.
Default Region Fill Opacity Set the default fill opacity (transparency) all regions have when first created.
Default Region Border Opacity Set the default border opacity (transparency) all regions have when first created.


Default Map View Type Sets the default map view type used in the geofence editor.
Initial Map Zoom Level Sets the initial zoom level used in the geofence editor.
Load Previous Geodata on Startup Determines whether the geofence editor loads previously saved geodata on application startup.
Invalid Region Color Sets the color used to highlight invalid regions in the geofence editor.
